# 📹 Apna Video Call

A full-stack video conferencing application inspired by Zoom, built using the **MERN Stack**. It allows users to connect through real-time video and audio calls, share screens, exchange messages, and manage meeting history.

## ✨ Features

- 🔐 User Registration and Login
- 🎥 Real-time Video Conferencing
- 🎙️ Audio and Video Controls
- 🖥️ Screen Sharing
- 💬 Real-time Chat
- 👥 Join Meetings as a Guest
- 📋 Meeting History

## 🛠️ Tech Stack

- **Frontend:** React.js, Material UI, CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Real-time Communication:** Socket.IO, WebRTC
- **Authentication:** bcrypt

## ⚙️ Installation

```bash
# Clone repository
git clone https://github.com/YOUR-USERNAME/ZOOM.git

# Backend setup
cd ZOOM/backend
npm install
npm start

# Frontend setup (new terminal)
cd ZOOM/frontend
npm install
npm start
```

Configure your MongoDB connection and environment variables in the backend `.env` file before running the application.
