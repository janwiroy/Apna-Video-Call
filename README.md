# 📹 Apna Video Call

A real-time video conferencing web application built using the **MERN Stack**. It allows users to connect through video calls, communicate with others, share screens, and manage their meeting history.

## ✨ Features

- 🔐 User Registration and Login
- 🎥 Real-time Video Conferencing
- 🎙️ Audio and Video Controls
- 🖥️ Screen Sharing
- 💬 Real-time Chat
- 👥 Join Meetings as a Guest
- 📋 Meeting History

## 🛠️ Tech Stack

- **Frontend:** React.js, Material UI, CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Real-time Communication:** Socket.IO, WebRTC
- **Authentication:** bcrypt

## ⚙️ Installation

```bash
git clone https://github.com/janwiroy/Apna-Video-Call.git
cd Apna-Video-Call

# Backend
cd backend
npm install
npm start

# Frontend (open a new terminal)
cd frontend
npm install
npm start
```

Configure your MongoDB connection and environment variables before running the application.
